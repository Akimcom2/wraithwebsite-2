# Зеркалье: вторая пачка

Игровой хаб для Бара, Майи, Акакия и Андрея. Сайт опубликован на https://wraithwebsite-2.vercel.app и автоматически обновляется коммитами в main.

## Для игроков

- Главная: настроение кампании и быстрые переходы.
- Персонажи: только краткие публичные знакомства.
- Атлас Ростова: поиск, категории, избранные места, масштаб и просмотр иллюстраций.
- За игровым столом: подготовка, краткая памятка и идеи специализаций.
- Мой блокнот: факты, версии и вопросы, экспорт Markdown, резервная копия JSON и восстановление.
- Хроника: только события уже сыгранных сессий. До первой игры массив пуст.

Заметки и настройки сохраняются локально в браузере и не отправляются мастеру. Для переноса на другое устройство используйте резервную копию. У каждой пачки собственное пространство хранения.

## Как обновлять

Контент находится в dist/content.js, разметка в dist/index.html, логика в dist/app.js, оформление в dist/style.css. Изменения в main запускают существующий деплой Vercel, выходная папка dist. Команда сборки не требуется.

Перед публикацией проверяйте краткие описания и каждый выводимый массив. Не добавляйте планы первой игры, причины смерти, NPC будущих сцен, скрытые связи, Тени персонажей, пророчества и мастерские тайны. Скрытая вкладка не является защитой: её данные также доступны игрокам.

Карты и изображения городских локаций хранятся только в JPG или PNG. Для новой локации добавляйте файл и запись в places либо mapGallery. Следите, чтобы id не менялся при обновлении описания: избранное ссылается на него.

## Проверка

Проверить синтаксис: node --check dist/app.js и node --check dist/content.js. Проверить, что все ссылки на изображения существуют и ни один файл не имеет нулевого размера. После деплоя проверить поиск, карточку персонажа, атлас, чеклист и сохранение блокнота.
