# Зеркалье: вторая пачка

Игровой архив кампании. Публичная версия: https://wraithwebsite-2.vercel.app. Коммиты в main запускают существующий деплой Vercel; выходная папка — dist.

## Возможности архива

- Главная страница с названием и вступлением кампании.
- Карточки игровых и неигровых персонажей с портретами.
- Атлас мест, галерея иллюстраций и карта с перетаскиваемыми маркерами.
- Подготовка к игре, памятка «За игровым столом» и специализации.
- Хроника с публикацией итогов и разделом «Воспоминания» для 1–20 изображений на сессию.
- Личный блокнот игрока с локальным сохранением, экспортом и восстановлением.

## Редактор мастера

В разделе «Хроника» откройте «Редактор кампании» и введите пароль мастера. Для добавления и изменения записей доступны:

- настройки кампании: название, система, место действия, подписи, начальный экран и фон карты;
- игровые персонажи и другие лица;
- места и иллюстрации Атласа;
- правила, пункты подготовки и специализации.

Новые места сначала попадают в список «не размещены». В Атласе перетащите карточку места на нужное место карты. Существующие маркеры также можно перетаскивать. Удаление материалов из редактора — мягкое: запись скрывается с публичных страниц и может быть возвращена мастером. Скрытые элементы не включаются в публичный ответ API; после входа мастера они загружаются в редактор.

Текст и материалы кампании редактор хранит в отдельном закрытом хранилище по пути campaign/site-content.json. Файлы, загруженные через сайт, хранятся в campaign/media/. Эти пути не пересекаются с данными Хроники: публикации и изображения сессий остаются в chronicle/entries.json и chronicle/memories/.

После изменения названия, места действия и других начальных настроек используйте «Скачать конфигурацию». Файл campaign-config.js можно положить в dist/ и включить в репозиторий, чтобы задать начальное наполнение кампании для всех посетителей. Изменения через сайт сразу сохраняются в закрытом хранилище и отображаются без коммита. Пароль мастера не записывается в файлы.

## Файлы кампании

- dist/campaign-config.js — настройки и исходное наполнение этой кампании.
- dist/campaign-config.example.js — чистый пример конфигурации для новой кампании.
- dist/campaign-bootstrap.js — загружает сохранённые настройки кампании и затем запускает интерфейс.
- dist/campaign-admin.js — защищённый мастерский редактор.
- dist/app.js — интерфейс и публичные разделы.
- dist/index.html — разметка.
- dist/style.css — стили.
- api/campaign-content.js — чтение и сохранение материалов кампании; скрытые записи доступны только с действующей сессией мастера.
- api/campaign-media.js — выдача загруженных изображений из закрытого хранилища.

Для новой кампании скопируйте dist/campaign-config.example.js в dist/campaign-config.js, заполните party и campaignInfo и оставьте пустыми массивы, которые мастер будет собирать через сайт.

## Проверка и сохранность

Синтаксис клиентских и серверных файлов проверяется через node --check. Изменения сайта не меняют API Хроники и не заполняют её за мастера. Перед этим изменением создана резервная ветка backup/pre-campaign-content-builder-20261013 от исходного состояния сайта второй пачки.
