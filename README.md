# Зеркалье — сайт новой группы

Отдельный сайт настольной кампании «Зеркалье» по Wraith: The Oblivion. Карта Ростова, известные места и раздел хроники перенесены из первого сайта. Досье прежних игроков и их портреты здесь отсутствуют.

## Содержимое

- `dist/index.html` — страницы и навигация;
- `dist/content.js` — персонажи новой группы, записи хроники и места на карте;
- `dist/app.js`, `dist/style.css` — поведение и оформление;
- `dist/assets/` — карта, иллюстрации мест и значки.

Массив `characters` в `dist/content.js` пока пуст. Новые персонажи появятся на сайте после добавления карточек с портретами. `chronicle` также пока пуст; раздел готов для записей новых сессий. Перед добавлением записей проверяйте их на сюжетные спойлеры для игроков.

## Vercel

Импортируйте **этот** репозиторий как новый проект Vercel. Корень проекта — корень репозитория, выходная папка — `dist`. Команда сборки не нужна: сайт состоит из статических файлов, настройки приведены в `vercel.json`. Создайте отдельный проект и адрес, чтобы первый сайт продолжил работать независимо.
